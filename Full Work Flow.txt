## 🚀 Setup Guide

### Prerequisites
- AWS Account (Free Tier)
- Cloudflare Account (Free)
- Telegram Bot (via BotFather)

### Step 1: Create DynamoDB Table
- Table name: `BrainSparkHistory`
- Partition key: `date` (String)

### Step 2: Create S3 Bucket
- Bucket name: `brainspark-dashboard-[yourname]`
- Enable Static Website Hosting
- Set public read bucket policy

### Step 3: Create Lambda Function
- Runtime: Python 3.12
- Timeout: 60 seconds
- Memory: 256 MB
- Paste code from `lambda_function.py`

### Step 4: Set Environment Variables
TELEGRAM_BOT_TOKEN=your_bot_token TELEGRAM_CHAT_ID=your_chat_id CLOUDFLARE_ACCOUNT_ID=your_account_id CLOUDFLARE_API_TOKEN=your_api_token S3_BUCKET_NAME=your_bucket_name DYNAMODB_TABLE=BrainSparkHistory


### Step 5: Create EventBridge Schedule
- Cron: `30 1 * * ? *` (7:00 AM IST)
- Target: BrainSparkAgent Lambda

### Step 6: Add IAM Permissions
Lambda role needs:
- `AmazonDynamoDBFullAccess`
- `AmazonS3FullAccess`
